# 오늘의 그림일기

알람 끄기부터 칼퇴 눈치싸움까지, 미니게임 5개로 하루를 버티면 그날의 그림일기가 완성되는 모바일 웹게임입니다.

| 시각 | 미니게임 | 하는 법 |
|---|---|---|
| 07:00 | 알람 끄기 | 움직이는 [일어나기]를 4번 누르기. [5분만 더]는 5분 손해 |
| 08:10 | 지옥철 버티기 | 기우는 반대쪽 버튼을 눌러 15초 버티기 |
| 12:00 | 점심 메뉴 고르기 | 모두의 조건에 맞는 메뉴 고르기 (3라운드) |
| 14:30 | 오후 졸음 참기 | 톡톡 눌러 눈 뜨기, 부장님 올 때 들키지 않기 |
| 18:00 | 칼퇴 눈치싸움 | 꾹 눌러 문으로, "흠흠" 하면 멈추기 |

끝나면 날씨·제목·크레파스 그림·원고지 글·선생님 도장이 들어간 그림일기 카드(PNG)를 공유하거나 저장할 수 있어요.

- 정적 파일만 사용 (index.html, style.css, game.js, diary.js) → GitHub Pages로 바로 배포
- 테스트용: `?demo=0`(잘한 날) `?demo=1` `?demo=2`(망한 날)로 일기 화면 바로 보기
