# 붕어빵 사장님

겨울 골목 붕어빵 가게를 운영하는 모바일 웹게임입니다.

## 굽는 순서
1. 반죽 주전자로 틀을 꾹 눌러 절반쯤 붓기 (초록 칸)
2. 속 넣기: 팥 · 슈크림 · 초코(2일차) · 피자(3일차)
3. 반죽을 가득(초록 칸)까지 마저 붓기 — 너무 많으면 넘침
4. 덮기 → 아랫면이 익으면 뒤집기 → 윗면이 익으면 꺼내기
5. 반죽을 붓는 순간부터 익기 시작, 오래 두면 탐

진열대에 모인 붕어빵을 손님을 눌러 건네면 돈을 받습니다. 하루 90초 영업 후 번 돈으로 틀 추가·화력·난로·간판을 업그레이드합니다. 진행은 브라우저(localStorage)에 저장됩니다.

- 정적 파일만 사용 (index.html, style.css, game.js, ads.js) → GitHub Pages로 바로 배포
- 광고 자리: `ads.js` (판 사이 광고, 순이익 2배 보상형). 승인 전에는 광고 없이 동작
