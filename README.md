# 붕어빵 사장님

겨울 골목 붕어빵 가게를 운영하는 모바일 웹게임입니다.

## 굽는 순서
1. 반죽 주전자로 틀을 꾹 눌러 절반쯤 붓기 (초록 칸)
2. 속 넣기: 팥 · 슈크림 · 초코(2일차) · 피자(3일차)
3. 반죽을 가득(초록 칸)까지 마저 붓기 — 너무 많으면 넘침
4. 덮기 → 아랫면이 익으면 뒤집기 → 윗면이 익으면 꺼내기
5. 반죽을 붓는 순간부터 익기 시작, 오래 두면 탐

진열대에 모인 붕어빵을 손님을 눌러 건네면 돈을 받습니다. 하루 90초 영업 후 번 돈으로 틀 추가·화력·난로·간판을 업그레이드합니다. 진행은 브라우저(localStorage)에 저장됩니다.

## 육성 요소 (1차)
- 달력: 하루 장사 = 게임 속 1주, 1주차는 11월 1주. 겨울 성수기 / 여름 비수기 (손님 수 차이)
- 아침 뉴스: 매주 장사 전 계절·상황 안내
- 위기 카드 4종: 팥값 폭등(3주), 최강 한파, 위생 점검(탄 붕어빵 많으면 다음 주 영업정지), SNS 대박 — 대응 선택지
- 2단계 '내 가게': 50,000원, 손님 +30%, 진열대 24개, 매주 월세 6,000원
- 평점: 붕어빵 별과 손님 만족으로 서서히 변함

- 정적 파일만 사용 (index.html, style.css, game.js, ads.js) → GitHub Pages로 바로 배포
- 광고 자리: `ads.js` (판 사이 광고, 순이익 2배 보상형). 승인 전에는 광고 없이 동작

## 육성 요소 (2차)
- 사장님 책상: 업그레이드 / 가게 확장 / 은행 탭
- 가게 확장: 가상 동네 5곳(학원가·역 앞·대학가·주택가·관광지), 본점 + 평점 ★4.0 이상이면 직영점 출점(12만·18만·25만·33만원)
- 점장 후보 3명 중 고용(실력 ★1~5, 주급), 직영점은 매주 자동 정산(동네 손님·계절·평점·점장 실력·위기 반영, 재료비 30%·월세·주급 차감)
- 은행: 5만원 단위 대출, 한도 10만 + 본점 5만 + 직영점당 5만, 이자 주 2%
- 돈이 4주 연속 마이너스면 파산 → 생존 게임처럼 모든 걸 잃고 포장마차(1년차 11월 1주)부터 다시. 남는 건 최고 생존 기록뿐

## PC 화면
- 가로로 넓은 화면(폭 1000px 이상, 가로:세로 1.25 이상)에서는 게임 뒤가 연말 밤거리(가게·전구줄·트리·가로등·눈)로 바뀌고, 사람들이 인도를 오가요. 손님이 오면 거리에서 가게로 걸어 들어가고, 다 사면 붕어빵 봉투를 들고 나가요(street.js). 장식은 게임 달력(11~2월 전구, 12·1월 트리)을 따라가요.
- 양끝 반투명 현황판: 날짜·계절, 이번 주 소식, 내 가게들(직영점 예상 수익), 기록 / 지갑, 이번 주 장부(진행 중), 주문 현황, 단축키
- 단축키: 1~5 재료, Q W E A S D 틀(누르고 있으면 반죽), Space 마지막 틀 덮기·뒤집기·꺼내기, Z X C 손님, P 일시정지, H 단축키 안내 열기/닫기

## 육성 3차
- 사장님 책상 '광고·본사' 탭: 인지도(가게 수·평점·손님 반응으로 오르내림, 최대 손님 +25%), 광고 3종(주 1회)
- 프랜차이즈 본사(직영점 4곳 + 인지도 40 + 40만원): 가맹 문의 계약(가맹비 10만원), 로열티 5·8·12%, 점주 만족도(30 아래면 이탈 가능), 본사 운영비
- 위기: 가상 감염병 '훌쩍열' 대유행(6주, 포장·배달/직영점 휴업/버티기, 긴급 지원금 = 보상형 광고 자리), 호떡 체인 등장, 가맹점주 로열티 인하 요구
- 업그레이드 '자동 반죽 주전자'(2만원): 톡 누르면 절반(45%) → 가득(94%)까지 알아서 부음
- 덜 익은 붕어빵(한 면이라도 초록 칸 전)을 팔면 손님이 배탈 → 1개당 합의금 30,000원, 팁 없음, 인지도 하락. 진열대에 🤢 개수가 뜨고, 진열대를 누르면 덜 익은 것부터(없으면 별 적은 1개) 버림
